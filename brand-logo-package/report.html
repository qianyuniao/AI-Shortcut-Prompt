色彩：墨松绿 #0B6E62（脱离 OpenAI 亮绿与 AI 蓝紫渐变）+ 琥珀 #F2A33C 仅 8.56%，只用于「被点亮的捷径」。

§1

概念与决策链

部件语义来源承载语义（一元素多义）删减测试
圆角卡片产品形态：5000+ 提示词以卡片呈现提示词载体 / 库 / 一张可用的「答案」删掉 → 无载体，故事不成立
45° 切角名字字义 Shortcut + 品类动作「一步到位」抄近道 / 果断 / 缺口即入口删掉 → 退化为普通圆角方块，无记忆点
琥珀折片被切下的那段路（沿切边镜像翻折）被跳过的试错 / 书签标记 / 点亮的捷径删掉 → 「捷径」失去被点亮的落点，且 mono 层级消失

内部落选方向（探索成本不摊给用户）： ①「⌘K 键」——与 Raycast 强撞且是 Apple 专用符号，弃； ②「叠层双卡（copy 语义）」——与系统 copy 图标通用语汇重合，16px 下两卡糊成一团，弃； ③「S 曲线字标」——字母锚定会削弱国际化（18 语言）场景的图形独立性，弃。

决策记录 DR

#决策依据量化证据
D1概念取「折」而非「AI 神经/芯片/星芒」行业俗套黑名单（知识源 B §2）+ 项目旧标即芯片+节点+渐变绿旧元素 100% 弃用；新标 0 个 AI 行业高频符号
D2主形 = 圆角卡片（品类载体）元素预算 ≤3、主角唯一主角占比 91.4%（1 − 折片 8.56%）
D3切角取 45° 且 CUT = B/2斜边 452.5 < 直角路径 640，捷径是几何事实省 29.3% 路径长度（1 − 452.5/640）
D4折片 = 切下三角沿切边镜像（非另画形状）数学必然：镜像唯一解，且面积 = 缺口面积折片 = 缺口 = 51200 px²，误差 0
D5折痕共享、仅两直角边留缝物理正确（折角沿折痕相连）；且保住单色可辨首版三边带缝被视觉判为「贴上去的异物」，改后异物感 0
D6比例系统取整数比而非 φ开发者工具气质（稳定/工程感）；且全参数落在 8U 网格6 项比例校验误差均为 0.000%
D7折片占比压到 8.56%点缀色纪律 <10%（知识源 F §2）首版 12.14% 超标 → 调 CUT/GAP 后达标
D8光学配平取质心补偿 40%全量补偿 48.4px = B 的 7.6%，超出 2–5% 经验区间取 40% = 20.5px = B 的 3.0%
D9强调手段用颜色不用加形状知识源 F §5：加形状会破元素预算与全形语法元素预算 1/3，无新增形状；mono 退化已诚实声明
