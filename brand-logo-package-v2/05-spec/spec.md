# AiShort 标志使用规范 v2.0

**方向：一格之距 · One of Many**　比例系统：整数比 + 8pt 网格

> 一张 2×2 的提示词卡片阵列，只有右下那一格是实的。
> 5000+ 条提示词里，你要的永远只有一条——标志只画这一条，其余三格退成浅青。

---

## 1. 标志本体

| 项 | 内容 |
|---|---|
| 构成元素 | 4 个等大圆角正方形，2×2 排列，间隙等于半格 |
| 主图形 | 右下格，青绿实色 |
| 辅图形 | 其余三格，浅青 |
| 唯一识别点 | 「哪一格是实的」——颜色差 + 明度差双重编码 |
| 可否只用纯图形 | 可以，且不依赖字标（右下格实色即为完整语义） |

**一句话描述（不出现产品名）**：一个四格方阵，只有最后一格被填满。

---

## 2. 推导链（每个图元都可回溯到产品截图的观察事实）

| 品牌语义 | 观察到的空间事实（评分） | 几何决策 | 24px 判据 |
|---|---|---|---|
| 提示词库 / 卡片 | 界面 4 列等宽圆角卡片网格（**High**） | 2×2 圆角方阵，间隙 G = B/2 | 4 格 + 十字负空间可辨 ✓ |
| 一秒找到那一条 | 唯一一处青色高亮描边框，出现在「被选中」卡片上（**High**） | 一格实色、三格浅色，用明度差而非描边表达 | 明度差 2.41:1，可辨 ✓ |
| 复制 / 取走 | 每张卡底部成对出现复制 + 收藏按钮（**High**） | 不画图标，退为「实/虚」对偶 | 已抽象，不参与小尺寸识别 ✓ |
| 抄近道 Shortcut | 青色细竖线、斜向高亮（Medium） | 不落地为图元，由品牌名承担 | 删掉后主族仍成立 ✓ |
| 留白 | 卡片间均匀深色间隙（**High**） | G = B/2，负空间占比 60.9% | 16px 下十字间隙 2.5px 未闭合 ✓ |

**未采用的 Low 评分事实**：4 列的具体数量、标签胶囊形状、心形图标、文字层级——全部依赖细节或数量，24px 下不可辨，一律不进入标志。

## 3. 几何与比例

全部落在 U = 8pt 网格上，比例为整数比。

| 参数 | 值 | 网格 | 说明 |
|---|---|---|---|
| 画布 CANVAS | 1024 | 128U | 2M + 2B + G = 1024 |
| 格边长 B | 320 | 40U | — |
| 间隙 G | 160 | 20U | G = B/2 |
| 圆角 R | 80 | 10U | R = G/2 |
| 边距 M | 112 | 14U | 上下左右等距 |
| 阵列总宽 | 800 | 100U | — |

| 比例校验 | 实测 | 期望 | 误差 |
|---|---|---|---|
| B : R | 4.0000 | 4 : 1 | 0.000% |
| B : G | 2.0000 | 2 : 1 | 0.000% |
| G : R | 2.0000 | 2 : 1 | 0.000% |
| 阵列 : 画布 | 0.7812 | 25 : 32 | 0.000% |
| M : B | 0.3500 | 7 : 20 | 0.000% |
| CANVAS : U | 128.0000 | 128 | 0.000% |

| 构图指标 | 值 |
|---|---|
| 几何质心 | (512.0, 512.0) = 画布中心 → 形态对称，无需光学配平偏移 |
| 四格占地 | 39.1% |
| 负空间 | 60.9%（满足 pre-flight 的 65–75% 留白纪律的宽松下界，图形类标志的合理区间） |

> **设计说明**：第一版原型取 B:G = 11:3（间隙 96），16px 实测时两列糊成一条横线，判定失败。
> 间隙加倍至 G = B/2 后，16px 下十字负空间仍有 2.5px，四格重新分离——这是本版唯一的重大返工。

| 角色 | HEX | RGB | HSL | CMYK | vs 白底 | vs #14171A |

\* 以脚本实测为准，表中为近似换算。

### 4.2 关键配对对比度

| 配对 | 对比度 | 判定 |
|---|---|---|
| teal ↔ mist（点亮 vs 未点亮） | **2.41 : 1** | ✓ 相邻色块可区分 |
| teal ↔ 白底 | **3.57 : 1** | ✓ 过 WCAG 1.4.11 非文本 3:1 |
| pine ↔ 白底（字标） | **6.14 : 1** | ✓ 过 WCAG 文字 4.5:1 |
| ink ↔ gray（单色版） | **5.68 : 1** | ✓ |
| 实底图标三层（底板 / 三格 / 点亮格） | 2.27 / 2.70 / 6.14 | ✓ 三层全部分离 |

### 4.3 色彩纪律

- **1 主色 + 1 结构色 + 至多 1 点缀**：teal（主）+ pine（结构）+ mist（浅阶，属主色阶不另计）。
- 全部取自产品截图已有的青绿色系（站点 `--ifm-color-primary` 为 hsl(163 38%)，本系统收束到 hsl(169–173)）。
- **禁止**：渐变、阴影、外发光、纹理、投影。
- **禁止**：给三格未点亮格换成别的色相——它们必须是主色的浅阶，否则色彩纪律崩坏。

## 5. 变体清单

| 变体 | 三格 | 点亮格 | 用途 |
|---|---|---|---|
| fullcolor | `#A9DFD5` | `#10997F` | 默认，白底/浅底 |
| highcontrast | `#A9DFD5` | `#0B6E62` | 小尺寸、低质印刷、单色屏 |
| mono-black | `#8A9296` | `#14171A` | 单墨印刷、烫金、雕刻 |
| grayscale | `#8A9296` | `#14171A` | 灰度文档、报纸 |
| darkmode | `#2F3839` | `#3FC2A9` | 深色底（`#14171A`） |
| reversed | white 30% | white 100% | 深色底纯反白 |
| 实底图标 | `#6DA8A1` | `#FFFFFF` | 底板 `#0B6E62`，favicon / App 图标 |

**单色说明**：单墨印刷时，未点亮的三格使用主墨的 **45% 网点（半调）**，点亮格 100% 实底。若印刷工艺不支持半调（如雕刻、冲压），必须改用实底图标版——纯剪影状态下四格同色，「哪一格被点亮」的信息会丢失，这是已知的有损降级。

## 7. 最小尺寸

| 形态 | 最小尺寸 | 依据 |
|---|---|---|
| 实底图标版 | **16 px** | 三层明度 ≥ 2.27:1，实测可辨 |
| 纯图形（全彩 / 高对比 / 单色） | **24 px** | 16px 下浅青格与白底仅 1.48:1，需半调支撑；24px 起稳定 |
| 横版组合（图形 + 字标） | **32 px 高** | 字标 cap 高度 ≈ 0.72 × 字号，低于 32px 时字形糊 |
| 竖版组合 | **96 px 宽** | 同上 |

低于 16px 一律使用实底图标版，不要缩放透明底版本。

## 9. 禁用项

| 禁用 | 原因 |
|---|---|
| 拉伸、压扁、非等比缩放 | 破坏 B:G = 2:1 |
| 旋转任意角度（非 90° 倍数） | 阵列轴与界面卡片网格失配 |
| 把点亮格挪到别的角 | 「读序终点落在答案上」是语义的一部分 |
| 给标志加渐变 / 阴影 / 外发光 / 描边 | 色彩纪律 |
| 四格改成 2×3、3×3 等其它数量 | 阵列数量不是识别点，但改动会稀释唯一性 |
| 三格换成其它色相 | 破坏主色浅阶关系 |
| 低于 16px 使用透明底版 | 浅青格与白底糊在一起 |
| 在净空区 X 内放置任何元素 | 规范 |
| 用字标字体以外的字体替换「AiShort」 | 字标锁定宽度 652（横版）/ 620（竖版） |
